╔══════════════════════════════════════════════════════════════════════╗
║  🎯 COMO USAR O SISTEMA                                             ║
╚══════════════════════════════════════════════════════════════════════╝

ADICIONAR NOVO PROJETO (Admin):
1. Faça login como admin
2. No menu lateral, clique em "Projetos Sustentáveis"
3. Clique no botão verde "+ Novo Projeto"
4. Preencha: Título, Categoria, Descrição
5. Faça upload de uma imagem OU cole URL
6. Clique em "Salvar Projeto"

ADICIONAR MÍDIA NA GALERIA (Admin):
1. No menu lateral, clique em "Galeria"
2. Clique no botão verde "+ Nova Mídia"
3. Preencha os dados
4. Faça upload do arquivo
5. Clique em "Salvar"

FAZER UPLOAD DE ARQUIVOS (Admin):
1. No menu lateral, clique em "Upload"
2. Arraste arquivos para a área ou clique nela
3. Escolha a categoria
4. Adicione descrição
5. Clique em "Fazer Upload"
