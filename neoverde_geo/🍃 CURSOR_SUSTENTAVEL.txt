═══════════════════════════════════════════════════════════════════
🎯 COMO FUNCIONA
═══════════════════════════════════════════════════════════════════

INICIALIZAÇÃO:
1. Verifica se não é mobile
2. Cria elementos do cursor
3. Adiciona ao body
4. Inicia animação loop

MOVIMENTO:
1. Captura posição do mouse
2. Atualiza cursor principal (rápido)
3. Atualiza follower (com delay)
4. Cria rastro a cada 50ms

INTERAÇÕES:
1. Hover: Adiciona classe .hover
2. Click: Adiciona classe .click + partículas
3. Mouse out: Esconde cursor
4. Mouse in: Mostra cursor

OBSERVADOR:
• MutationObserver para novos elementos
• Adiciona eventos automaticamente
• Funciona com conteúdo dinâmico
