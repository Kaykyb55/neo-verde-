🎯 COMO USAR AS NOVAS FUNCIONALIDADES
═══════════════════════════════════════════════════════════════════

EDITAR FOTO DA GALERIA:
─────────────────────────
1. Vá para: Admin → Galeria
2. Clique no botão "✏️ Editar" da foto
3. Modal abre com dados atuais
4. Edite título, descrição ou categoria
5. Clique em "Salvar"
6. ✅ Foto atualizada!

EDITAR PROJETO:
────────────────
1. Vá para: Admin → Projetos Sustentáveis
2. Clique no botão "✏️ Editar" do projeto
3. Modal abre com dados atuais
4. Edite título, descrição, categoria
5. OPCIONAL: Troque a imagem
   - Upload novo arquivo OU
   - Cole nova URL
6. Clique em "Salvar Projeto"
7. ✅ Projeto atualizado!

DELETAR MENSAGEM:
──────────────────
1. Vá para: Admin → Mensagens
2. Clique no botão "🗑️ Deletar"
3. Confirme a exclusão
4. ✅ Mensagem deletada!
