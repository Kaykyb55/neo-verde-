📸 PASSO 3: FAZER UPLOAD DE FOTOS
═══════════════════════════════════════════════════════════════════

MÉTODO 1: Upload Simples (Modal)
─────────────────────────────────
1. No painel admin, vá para "Galeria"
2. Clique no botão "➕ Nova Mídia"
3. Preencha:
   - Título: Nome da foto
   - Descrição: Descrição da foto
   - Categoria: Escolha uma categoria
4. Clique em "Escolher arquivo" e selecione a foto
5. Veja o preview da foto
6. Clique em "Salvar"
7. ✅ Pronto! A foto aparece na galeria

MÉTODO 2: Upload Múltiplo (Drag & Drop) - RECOMENDADO!
────────────────────────────────────────────────────────
1. No painel admin, vá para "Upload"
2. ARRASTE as fotos para a área pontilhada
   OU
   Clique na área para selecionar múltiplas fotos
3. Configure:
   - Categoria: Escolha uma (vale para todas)
   - Descrição: Descrição geral (opcional)
4. Veja o preview de TODAS as fotos selecionadas
5. Clique em "📤 Fazer Upload"
6. ✅ Todas as fotos serão enviadas de uma vez!


═══════════════════════════════════════════════════════════════════
🌱 PASSO 4: CRIAR PROJETOS
═══════════════════════════════════════════════════════════════════

1. No painel admin, vá para "Projetos Sustentáveis"
2. Clique no botão "➕ Novo Projeto"
3. Preencha o formulário:
   
   ┌─────────────────────────────────────────────┐
   │ Título:      [Nome do Projeto]              │
   │ Categoria:   [Escolha uma categoria]        │
   │ Imagem:      [Fazer upload] ou [URL]        │
   │ Descrição:   [Descrição detalhada]          │
   └─────────────────────────────────────────────┘

4. Para a imagem, você pode:
   
   OPÇÃO A: Fazer upload de uma imagem do computador
   ▶ Clique em "Escolher arquivo"
   ▶ Selecione a imagem
   ▶ Veja o preview
   
   OPÇÃO B: Usar uma URL de imagem da internet
   ▶ Cole a URL no campo "URL da imagem"
   ▶ Exemplo: https://exemplo.com/foto.jpg

5. Clique em "💾 Salvar Projeto"
6. ✅ Projeto criado e visível no site!

🔍 RESOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════

❓ O upload não funciona?
▶ Verifique se você está LOGADO como admin
▶ Verifique o tamanho do arquivo (máx 50MB)
▶ Verifique o formato do arquivo
▶ Pressione F12 e veja o Console por erros

❓ As fotos não aparecem na galeria?
▶ Limpe o cache: Ctrl + F5
▶ Clique no botão "🔄 Refresh" no admin
▶ Verifique se o arquivo está em: static/uploads/

❓ Não consigo criar projeto?
▶ Preencha TODOS os campos obrigatórios
▶ Adicione pelo menos uma IMAGEM
▶ Verifique se a descrição não está vazia

❓ O servidor não inicia?
▶ Feche outros servidores na porta 5000
▶ Execute: py app.py
▶ Verifique se Python está instalado
